# 智能收纳助手

> 语音记录物品存放位置，再也不用担心找不到东西了。

智能收纳助手是一款基于 Android 的轻量级收纳管理工具，通过语音录入 + AI 智能解析，让您轻松记录和管理家中物品的位置信息。支持批量识别、多图附件、回收站、深色模式等丰富功能。

## ✨ 主要功能

- 🎙️ **语音录入**：点击麦克风说话，AI 自动提取物品名称和存放位置
- 🤖 **AI 智能解析**：支持单条和批量识别，自动提取物品信息
- 📦 **批量录入**：一次性说出多个物品，AI 逐一识别（如“红色的笔在柜子里，蓝色的笔在抽屉里”）
- 🖼️ **多图附件**：每个物品可上传最多 9 张照片辅助记忆
- 🔍 **智能搜索**：支持文字搜索、语音搜索、AI 关键词提取，模糊匹配更精准
- 🗑️ **回收站**：误删物品可随时恢复，数据安全有保障
- 🌙 **深色模式**：支持跟随系统或手动切换浅色/深色主题
