# 智能收纳助手 1.2.0 使用教程与更新说明

## 快速开始

1. 安装后首次打开 App，按引导了解记录、解析、查找和图片索引。
2. 在“添加物品”页输入或语音录入名称、地点和备注。
3. 需要识别多个物品时，点击“AI 解析”；解析完成后可逐条修改、分配照片，也可勾选多条后点击“合并选中物品”，确认合并后的字段和照片再保存。
4. 保存后在首页搜索名称、地点、备注或照片内容；使用照片搜索前，需要在设置中主动开启 AI 图片理解。
5. 在设置页可切换语言和主题、导出/导入备份、检查更新，或执行“完全删除 App 数据”。

## 图片索引

- 新照片和已保存物品的照片都可以单独创建或删除图片索引。
- 删除图片索引不会删除物品、照片文件或系统相册原图。
- 在照片上点击“创建图片索引”后，App 会先确认 AI 图片理解已开启并完成能力探测。
- 详情页会显示等待、分析中、已建立、失败、已过期和未创建状态；失败时可重试，已过期时点击刷新，已建立时点击删除。
- 等待或分析中时不会提供无提示删除；关闭 AI 图片理解后，尚未发送的复核照片不会继续上传。

## 批量识别与合并

- “充电线，放在书桌，第二个抽屉”会识别为一条物品，地点为“书桌第二个抽屉”。
- “一个充电器，两根数据线”会保留为两条，并保留各自数量。
- 合并多个物品会生成一条可编辑的新记录；不同地点和备注会带上原物品名，照片可选择并合并，最多 9 张。
- 取消合并不会修改原来的识别草稿。

## 数据安全

- 导出备份会包含物品、照片和成功建立的图片索引。
- 导入覆盖失败不会先清空原有数据；导入取消或失败时不会删除数据库仍引用的新图片。
- “完全删除 App 数据”会删除本机物品、回收站、App 私有照片、视觉索引、缓存、偏好设置、语言/主题与 API Key。
- 该操作不会删除系统相册原图、外部 ZIP 备份、其他应用数据、Android 云备份或 API 服务商远端数据。

## 1.2.0 更新内容

- 新增照片视觉找物和可单独创建的本地图片索引。
- 支持合并多个识别结果和照片。
- 改善语音输入造成的标点、停顿和重复词问题。
- 新增校园邮箱、GitHub 检查更新和完全删除 App 数据。
- 完善三语言提示、深色模式、视觉模型探测和旧版升级数据保护。
