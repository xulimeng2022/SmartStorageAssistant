## 1. 背景与目标

### 要解决的问题
- 家中物品多、存放位置靠记忆，找不到东西；需要一个轻量的“物品位置记录”工具。

### 本项目目标
- 用户用语音/文字口述即可记录“物品名 + 存放地点（+ 备注）”，随时搜索找回位置。
- 可观察结果：口述一句话 → App 解析出可编辑条目 → 保存后首页出现该物品；搜索能按名称/地点/备注命中。

### 成功标准（依据 README/发布说明，量化验收待确认）
- 核心链路（录入→保存→搜索→详情→回收站→备份）可独立在 Android 完成，不依赖服务端。
- 发布产物为可安装 APK（GitHub Releases 分发）；混淆 Release 可运行。

## 4. 核心使用流程

### 场景 A：单条录入
1. 首页点底部「添加」（或在添加 Tab 说话）。
2. 输入/口述描述，可点 AI 解析。
3. 系统展示可编辑的名称/地点/备注；用户确认或修改。
4. 点保存：重名则弹窗选择；成功后列表出现新物品，Star 里程碑计数 +1。

### 场景 B：搜索
1. 首页输入关键词（支持键盘语音整句）。
2. 普通搜索：去掉空白后逐字 `%x%y%z%` 模糊匹配名称/地点/备注，保留反向包含。
3. AI 语义搜索：把整句解析为名称/地点/描述三字段后精确筛选；解析失败有引导弹窗与本地降级。

### 异常流程（代码/文档已确认的行为）
| 情况 | 用户会看到什么 | 系统如何处理 | 人工介入 |
| --- | --- | --- | --- |
| AI 请求失败（超时/网络/服务端/鉴权/额度/限流/空结果） | 统一「AI 解析未成功」对话框 | 可「去配置 API」或「稍后」；稍后自动本地降级并保留结果继续填写，同会话不反复弹窗 | 配置 API 时 |
| 免费模式无内置 Key | 引导去设置切自定义模式 | 归类为配置缺失 | 用户填 Key |
| 保存遇到重名 | 弹「更新旧记录/新建记录/取消」 | 按选择更新/插入/停留 | 用户选择 |
| 批量部分条目失败（名称缺失/写入异常） | 失败条目保留待补 | 单条失败不影响其它条目 | 用户补名称后重试 |
| 照片无法读取/解码 | 失败提示 | 不阻塞手动填写 | 否 |
| 备份文件版本不兼容/缺 data.json | 导入失败提示 | 拒绝导入 | 否 |

## 5. 数据与集成

| 数据/系统 | 来源 | 用途 | 是否敏感 | 保存位置/期限 |
| --- | --- | --- | --- | --- |
| 物品记录 | 用户录入/AI 解析 | 清单/搜索/回收站 | 本地 | Room `items` 表（app 私有库） |
| 照片 | 相册/拍照 | 附件展示 | 本地 | `filesDir/item_images/` |
| AI 配置与外观 | 用户设置 | 解析与展示 | 部分敏感 | DataStore / EncryptedSharedPreferences |
| API Key | 用户输入或本地构建注入 | LLM 鉴权 | 敏感 | EncryptedSharedPreferences(AES-256-GCM)；免费 Key 仅经 BuildConfig 从 local.properties 注入 |
| LLM 服务 | 用户所选 OpenAI 兼容服务商 | 文本解析 | 仅发送口述文本 | 不落库；上传策略见「明确不做」 |

### 关键数据字段（items 表）
| 实体 | 字段 | 含义 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| Item | id | 自增主键 | 是 | 新增为 0 |
| Item | name | 物品名称 | 是 | 保存前按名称查重（忽略大小写） |
| Item | location | 存放地点 | 否 | 空串可 |
| Item | description | 备注 | 否 | 空串可 |
| Item | imagePaths | 照片绝对路径 JSON 数组 | 否 | 最多 9 |
| Item | createdAt/updatedAt | 毫秒时间戳 | 是 | 列表按 updated_at 倒序 |
| Item | deletedAt | 回收站标记 | 否 | null=正常，非 null=回收站 |

## 6. 非功能要求

- 使用环境：Android 8.0+（minSdk 26），target/compileSdk 35；单机离线可完成核心记录（联网仅用于 LLM 解析）。
- 性能/稳定性：本地记录即时反馈；LLM 连接超时 7s / 读取 25s，失败有界重试 2 次后降级，不阻塞手动填写。
- 隐私：数据与照片本地保存；Key 加密存储；备份 ZIP 由用户自行导出保存（上传/同步行为未确认）。
- 交付形态：源码仓库 + Release APK（混淆 + 资源压缩）。
