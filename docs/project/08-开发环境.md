## Gradle 与中文路径（重要，已在 gradle.properties 固化）
- 项目路径含中文（智能收纳助手）。
- `gradle.properties` 注释明确：不要添加 `-Dfile.encoding=UTF-8`——若 Gradle daemon 强制 UTF-8 而 Java 17 测试 worker 按系统默认编码（GBK）读 classpath，中文路径会乱码导致单元测试 `ClassNotFoundException`；保持 daemon 与 worker 同为系统默认编码即可正常跑测试与构建。
- 已设置 `android.overridePathCheck=true` 放行中文路径；`ksp.useKSP2=false` 统一 KSP1。
- Gradle 缓存：可用 `GRADLE_USER_HOME` 指向独立目录复用；跨工作树复制源码时排除 `.git`、`build`、`app/build`、`.gradle`（见仓库习惯），避免重复下载与缓存冲突。

## Git Worktree（长期 Multi-Codex）
- 当前阶段的长期角色工作区为 Coordinator / Integration、Data、AI、UI；Test 与 Review 当前按任务临时启动，不建立永久 Worktree。
- 永久 Worktree 是角色工作空间，不是一功能一 Worktree；当前四个长期角色从同一冻结基线创建，UI / Data / AI 之间无父子分支关系。
- Worktree ID、路径与状态运行时通过 `git worktree list --porcelain` 动态发现，不写死。
- `AGENTS.md`、`docs/`、核心 Gradle 配置、导航、数据库 Schema、核心数据模型属于易冲突文件，遵循 `AGENTS.md` 的 Ownership / Single Writer / contract 规则。
- 创建或进入工作树后先确认仓库、branch、HEAD 与工作区状态，避免在错误工作树操作。

## local.properties 职责（不入 Git）
- `sdk.dir`：本机 SDK 路径。
- `SILICONFLOW_API_KEY`：免费模式 Key（构建注入 BuildConfig）。
- `KEYSTORE_FILE / KEYSTORE_PASSWORD / KEY_ALIAS / KEY_PASSWORD`：Release 签名（未配置则不签名）。
- 值均为本机敏感信息，禁止复制进文档或提交；`local.properties` 已被 `.gitignore` 忽略。

## 已知坑位（已验证结论，非日志）
- PowerShell 写中文文件用 UTF-8 无 BOM；路径含空格/中文时用 `-LiteralPath` 并避免通配符与多层转义。
- 根目录 APK 与本地 `.bak-*` 备份已由 `.gitignore` 窄规则忽略；正式 APK 仍按 GitHub Releases 上传，`release/**/mapping.txt` 跟踪策略不变。
