# M08 首页与搜索

## 1. 职责与边界

### 模块职责
- 首页物品清单展示（名称/地点/缩略图），按 updated_at 倒序。
- 关键词搜索（实时逐字模糊）与 AI 语义搜索（整句→三字段精确筛选）。
- 区分「从未添加」与「搜索无结果」两种空状态；删除（移入回收站）与撤销。

### 不负责什么
- 不处理添加/编辑表单（M09）、详情（M10）、回收站页（M10）。

### 上下游关系
| 方向 | 模块 | 交换内容 | 约定 |
| --- | --- | --- | --- |
| 输入 | 用户 | 关键词/语音整句 | searchQuery |
| 输出 | M01 仓库 | SearchItemsUseCase / SearchItemsByFieldsUseCase | Flow<List<Item>> |
| 依赖 | M03 LlmClient（语义解析）、M06（文字颜色/搜索提示） | - | - |

## 2. 功能清单
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| M08-01 | 清单观察 | items = combine(searchQuery, aiFilter) → flatMapLatest 对应 UseCase |
| M08-02 | 关键词搜索 | 空白=全部；否则逐字模糊（见 M01） |
| M08-03 | AI 语义搜索 | 解析整句为 name/location/description 三字段 → SearchItemsByFieldsUseCase |
| M08-04 | 空状态 | isInitialEmpty=activeCount==0 区分“从未添加”/“搜索无结果” |
| M08-05 | 删除与撤销 | DeleteItemUseCase 软删除 + Snackbar 撤销（RestoreItemUseCase） |
| M08-06 | AI 失败引导 | 「AI 解析未成功」对话框；「稍后」本会话不再弹、用原文关键词搜索（freeSearchTimeoutFallback） |
| M08-07 | 外观联动 | 订阅 ThemeRepository.textColorConfig 实时应用文字颜色 |

## 3. 核心流程
1. HomeViewModel 组合 searchQuery + aiFilter：aiFilter 非空→三字段搜索；否则 query 空白→observeItems；否则 searchItems(query)。
2. AI 解析：LlmClient 解析（SearchParseOutcome.Keyword/Failed）；Failed(timedOut) → parseFailedGuide=true 弹窗。
3. 「去配置 API」→ 关弹窗保留输入；「稍后」→ 置 fallback 标志并保留原文关键词继续搜。

## 5. 状态、错误与排查
| 情况 | 处理 | 排查 |
| --- | --- | --- |
| AI 解析失败 | 弹窗两出口；稍后→本地关键词 | LlmClient（M03） |
| 无结果 | 「未找到」空态 | DAO 搜索 SQL |
