# M11 设置、外观与主题

## 1. 职责与边界

### 模块职责
- 设置页：AI 配置（预设/模型/Key 显示隐藏）、外观（主题模式、文字颜色实时预览）、多语言切换、数据备份入口、Star、回收站/关于/捐赠入口。
- 全局主题（Material3 换肤 + 微信式深色）与文字颜色样式应用。

### 不负责什么
- 持久化细节见 M06；备份逻辑见 M05；语言机制见 M06 AppLanguage。

## 3. 核心流程
1. SettingsViewModel 订阅 ThemeRepository.textColorConfig / themeMode / SettingsRepository config。
2. 主题切换：ThemeRepository.saveThemeMode → MainActivity 订阅 themeMode 全局换肤。
3. 文字颜色：保存 TextColorConfig → themeDataStore → textColorConfig StateFlow 全局（首页/详情/表单输入）实时更新。
4. 语言：AppLanguage.setCode + Activity.recreate（attachBaseContext 生效）。
5. AI 配置保存：saveConfig（Key 加密、其余 DataStore）。

## 4. 数据与接口
- 主题实现：`presentation/theme/{Theme.kt, Color.kt, Type.kt, TextColorStyles.kt}`；夜间主题资源 `res/values-night/themes.xml`（微信式深色）。
- 颜色选择：`settings/HsvColorPicker.kt`、`AppearanceSettings.kt`。
- 全局文字颜色作用于：首页清单、物品详情、添加/编辑输入框（统一使用）。

## 9. 外观/语言：完整行为约束（速查）

> 来源：原 AGENTS.md（v1.1.0）功能实现约束。改主题/语言相关代码时不得破坏以下语义。

- 深色模式：关闭 Android 12+ 动态取色，使用固定语义色板（微信式深灰层次，见 `Color.kt`/`Theme.kt`）；所有页面走 MaterialTheme.colorScheme。
- 界面语言：支持跟随系统 / 简体中文 / 繁體中文 / English。默认资源 `values/` 为简体（系统语言不受支持时的回退），另有 `values-zh-rTW`、`values-en`；选择经 `AppLanguage`（SharedPreferences）持久化，在 `SmartStorageApp`/`MainActivity.attachBaseContext` 同步应用，设置页切换后 `recreate()` 立即生效；语言与深浅主题独立、互不覆盖。
- 只本地化显示层：用户数据与稳定标识、JSON 键、LLM 提示词不翻译。
- 全局文字颜色作用于首页清单、物品详情、添加/编辑输入框（统一使用），经 `TextColorStyles`。
