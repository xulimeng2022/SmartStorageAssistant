## 3. 核心流程
### 批量保存（M02-09，v1.1.0）
1. 按勾选 uid 排序逐条处理：名称 trim 为空 → 记 failedUids（UI 保留重试）。
2. 有重名 → 挂起 `resolveDuplicate` 回调由 UI 弹窗决策（UPDATE_EXISTING/INSERT_NEW/SKIP）。
3. 照片归属：维护 `claimed` 占用集合（已占用路径 → 调 `copyFile` 复制独立副本；首次占用 → 原路径直存并记入 consumedOriginals，供重试防重复直存）；更新旧记录时旧照片保留并纳入占用。
4. 单条异常不影响其它条目；返回 added/updated/skipped/failedUids/consumedOriginals。

## 4. 数据与接口
### 模型
| 对象 | 字段 | 说明 |
| --- | --- | --- |
| Item | id/name/location/description/imagePaths/createdAt/updatedAt/deletedAt | 领域主模型；imagePath = 首图 |
| ParsedItem | name/location/description | AI/本地规则解析结果（未入库） |
| BatchDraftItem | uid/name/location/description/photoPaths | 批量草稿，uid 稳定标识；BatchDraftOps 提供纯函数增删/照片归属 |
| BatchDuplicateChoice | UPDATE_EXISTING/INSERT_NEW/SKIP | 批量重名决策 |

### 接口
`ItemRepository`：observeItems/observeActiveCount/observeItemById/observeTrash/searchItems/searchByFields/getItemByName/addItem/updateItem/deleteItem/restoreItem/permanentDeleteItem/emptyTrash。

## 5. 状态、错误与排查
| 情况 | 处理 |
| --- | --- |
| 批量条目名称为空 | 记 failedUids，UI 提示补充后重试 |
| 批量写入异常 | 单条记 failedUids，继续其余条目 |
| 照片共享冲突 | 路径占用判定 + copyFile 副本（见 BatchAddItemsUseCase） |
