# M10 详情、照片预览与回收站

## 1. 职责与边界

### 模块职责
- 物品详情页：查看/编辑入口、照片管理（删除单张、全屏缩放预览）。
- 回收站页：恢复、永久删除（二次确认）、清空（二次确认）。

### 不负责什么
- 不实现删除的物理文件清理细节（M01 负责先删文件再删记录）。

### 上下游关系
| 方向 | 模块 | 交换内容 | 约定 |
| --- | --- | --- | --- |
| 输入 | M07 覆盖层 / M08 列表 | Item/id | 从库观察 |
| 输出 | M02 用例 | 恢复/永久删除/清空 | 二次确认后执行 |
| 依赖 | M12 PhotoPreviewDialog | 全屏预览 | 手势缩放/翻页 |

## 2. 功能清单
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| M10-01 | 详情展示 | ObserveItemByIdUseCase 实时观察 |
| M10-02 | 照片管理 | 大图/全屏缩放预览、删除单张（同步库内 imagePaths） |
| M10-03 | 软删除入口 | 列表/详情删除 → Snackbar 撤销（M08 或详情） |
| M10-04 | 回收站恢复 | RestoreItemUseCase 置 deleted_at=null |
| M10-05 | 永久删除 | PermanentDeleteItemUseCase：先删照片再物理删记录，二次确认 |
| M10-06 | 清空回收站 | EmptyTrashUseCase：批量删照片+物理删除，二次确认 |

## 3. 核心流程
1. 详情：观察 byId；照片点击 → PhotoPreviewDialog 全屏（多图翻页 + 双指/点击缩放）。
2. 删除单张照片：从 imagePaths 移除并落库；文件清理按 M09/M01 规则（编辑流程）。
3. 回收站：observeTrash 按 deleted_at 倒序；恢复/永久删除/清空各自走用例，危险操作二次确认。
