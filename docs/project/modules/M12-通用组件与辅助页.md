# M12 通用组件与辅助页

## 1. 职责与边界

### 模块职责
- 跨页面通用组件：动画按钮、Emoji 彩蛋、图标按钮、链接打开、搜索提示/超时/AI 失败/全屏照片预览等对话框。
- 辅助页：关于页（版本/联系方式/更新记录入口）、捐赠页（多档位收款码 + 保存相册）。

### 不负责什么
- 不含主功能页业务（M08~M11）。

### 上下游关系
| 方向 | 模块 | 交换内容 | 约定 |
| --- | --- | --- | --- |
| 输入 | 各页面/设置页/关于页 | 事件/链接/图片 | - |
| 输出 | 用户 | Toast/浏览器选择器/弹窗/全屏预览 | - |
| 依赖 | 平台 Intent/FileProvider | 打开链接/保存图片 | - |

## 2. 功能清单
| 编号 | 组件/页 | 说明 |
| --- | --- | --- |
| M12-01 | AnimatedButton / EmojiIconButton | 主要按钮点击 Emoji 飘动彩蛋（最多 3 并发，结束自动回收） |
| M12-02 | EmojiEffect | 飘动动画层 |
| M12-03 | LinkOpener | openUrlWithChooser 打开 GitHub/个人网站等 |
| M12-04 | SearchTipsDialog | 搜索使用提示 |
| M12-05 | AiParseFailedDialog | AI 解析失败两出口（去配置 API / 稍后），v1.1.0 替代原 TimeoutDialog |
| M12-06 | PhotoPreviewDialog | 全屏照片预览（多图翻页 + 缩放），v1.1.0 |
| M12-07 | About 页 | 版本、联系方式复制、GitHub/网站打开、更新记录入口（v1.1.0） |
| M12-08 | Donate 页 | 多档位 DonateOption、收款码弹窗、保存到相册（Android 12 及以下需存储权限） |

## 3. 核心流程
1. 链接：openUrlWithChooser → Intent.ACTION_VIEW 系统选择器。
2. 收款码保存：写相册；`WRITE/READ_EXTERNAL_STORAGE` 仅 maxSdkVersion=32（Android 13+ 无需）。
3. 全屏预览：PhotoPreviewDialog 接收 imagePaths + 初始下标，翻页/手势缩放。

## 4. 数据与接口
- 对话框通用：AlertDialog/自定义 Dialog 封装（AiParseFailedDialog 位于 common/，供 M08/M09 使用）。
- DonateOption：档位数据模型（presentation/donate/DonateOption.kt）。
- 权限相关：Manifest 中 RECORD_AUDIO 仅声明（语音走键盘）；相机为运行时申请（添加页）。

## 5. 状态、错误与排查
| 情况 | 处理 |
| --- | --- |
| 无浏览器/打开失败 | 系统选择器兜底/无操作 |
| 保存相册权限不足（≤Android 12） | 运行时申请或提示 |
