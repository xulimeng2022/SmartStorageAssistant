# M06 偏好与配置存储

## 1. 职责与边界

### 模块职责
- 持久化 AI 配置（预设/Base URL/模型/模式）与各预设 API Key（加密）。
- 持久化主题模式、全局文字颜色、引导页状态、Star 里程碑状态、界面语言。
- 提供旧版单一 Key / 模型名 / 文字颜色的迁移。

### 不负责什么
- 不调用 LLM（M03 消费本模块配置）；不含物品数据（M01）；不含备份逻辑（M05）。

### 上下游关系
| 方向 | 模块 | 交换内容 | 约定 |
| --- | --- | --- | --- |
| 输入 | M11 设置页 / M09 添加 / M07 框架 | 用户设置 | 经 Repository |
| 输出 | M03 LlmClient、M07 主题/语言、M09 Star | AiConfig/ThemeMode/语言码/里程碑 | 订阅 Flow 或挂起读 |

## 2. 存储介质一览（代码确认）
| 仓库/对象 | 介质（文件/DataStore 名） | 内容 |
| --- | --- | --- |
| SettingsRepository | DataStore `ai_settings` + EncryptedSharedPreferences `ai_api_key_secure` | preset_type/base_url/model_name_map/mode；api_key_map(JSON, AES-256-GCM) |
| ThemeRepository | DataStore `theme_prefs` | theme_mode、text_color_*（含旧值迁移标记） |
| OnboardingRepository | DataStore `onboarding` | is_first_launch |
| StarMilestoneRepository | DataStore `star_milestone` | total_added、star_reminded_5/15/30、star_remind_later_timestamp |
| AppLanguage | SharedPreferences `app_lang` | lang_code（空=跟随系统；zh/zh-rTW/en） |
| AppPreferencesRepository | SharedPreferences `app_prefs` | input_text_color（旧，已迁移）、search_tips_enabled |

## 3. 关键内容
### AI 配置（SettingsRepository）
- `AiConfig`：presetType/baseUrl/modelNameMap/apiKeyMap/mode（FREE/CUSTOM）；apiKey/modelName 从当前预设取。
- `FreeModel`：硅基流动 Qwen2.5-7B-Instruct；Key 仅经 BuildConfig（local.properties 注入），不落 DataStore。
- `LlmPreset` 预设：DeepSeek / 通义千问 / OpenAI / 智谱AI / Moonshot / 百川 / MiniMax / Anthropic / Google / 自定义（各自 baseUrl + 候选模型列表）。
- 各预设 API Key 独立加密存储（EncryptedSharedPreferences，MasterKeys AES256_GCM）；支持旧版单一 Key 迁移。

### 外观与语言
- `ThemeMode`：FOLLOW_SYSTEM(0)/LIGHT(1)/DARK(2)。
- `TextColorConfig`：DEFAULT/SOLID/GRADIENT（含渐变方向）；旧 `app_prefs.input_text_color` 幂等迁移到 theme DataStore。
- `AppLanguage`：在 `attachBaseContext`（Hilt 注入前）读取并 wrap，支持跟随系统/简/繁/英。

### Star 里程碑
- 里程碑 5/15/30；历史累计添加数新增成功 +1（删除不减）；点「稍后提醒」24h 后重弹（STAR_REMIND_LATER_MILLIS）；去 GitHub 后永久标记。

## 4. 状态、错误与排查
| 情况 | 处理 | 排查 |
| --- | --- | --- |
| 加密存储不可用（security-crypto 1.0） | MasterKeys 创建/读取 | SettingsRepository.encryptedPrefs |
| 旧数据迁移 | migrateLegacyApiKey / migrateLegacyModelName / migrateLegacyColorIfNeeded | 各仓库迁移方法 |
| JSON 解析失败 | parseStringMap 返回空表 | DataStore 内容损坏 |
