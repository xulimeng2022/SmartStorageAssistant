# M04 图片附件

## 1. 职责与边界

### 模块职责
- 把相册 Uri / 拍照临时文件压缩保存为应用私有图片（1080px 宽 / JPEG 80%），修正 EXIF 方向。
- 提供删除接口；配合 FileProvider 暴露私有目录供预览/相机。

### 不负责什么
- 不管理“照片归属哪条物品/批量分配”（M02/M09 的 BatchDraftItem 与 Item.imagePaths）。
- 不做图片的云端上传。

### 上下游关系
| 方向 | 模块 | 交换内容 | 约定 |
| --- | --- | --- | --- |
| 输入 | M09 添加页 / M10 详情 | Uri / File | 内容 Uri 或拍照文件 |
| 输出 | 上层 | 本地绝对路径（filesDir/item_images/item_时间戳.jpg） | 绝对路径入 imagePaths |
| 被依赖 | M01 Repository | 物理删除时清理文件 | permanentDelete/emptyTrash 先删文件 |

## 2. 功能清单
| 编号 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| M04-01 | saveFromUri | content Uri | 本地路径（先落 cache 临时文件再压缩） |
| M04-02 | saveFromFile | 文件 | 本地路径（采样/缩放/EXIF 旋转/JPEG 压缩） |
| M04-03 | deleteImage | 路径/null | -（runCatching 忽略失败） |

## 3. 核心流程
1. 读 EXIF orientation；`inJustDecodeBounds` 读取尺寸 → `calculateInSampleSize` 防内存峰值。
2. `decodeFile` → `scaleToWidth(1080)`（超过才缩放）→ 按方向 `postRotate`。
3. 写入 `filesDir/item_images/item_<时间戳>.jpg`（JPEG quality 80）；清理 cacheDir 下的临时文件。
4. 返回绝对路径；路径进入工作副本，保存成功才落库。

## 4. 数据与接口
- 存储位置：`context.filesDir/item_images/`；命名 `item_<epochMillis>.jpg`。
- FileProvider：authorities `${applicationId}.fileprovider`，paths 见 `res/xml/file_paths.xml`（Manifest 已声明）。
- 数量上限：每件 9 张（`AddItemViewModel.MAX_IMAGES` 与 `BatchAddItemsUseCase.MAX_IMAGES_PER_ITEM` 均为 9）。

## 5. 状态、错误与排查
| 情况 | 处理 | 排查 |
| --- | --- | --- |
| Uri 无法打开 | checkNotNull 抛错，上层提示 | contentResolver/权限 |
| 图片解码失败 | 抛 IllegalStateException | 文件损坏/超大 |
| 删除失败 | runCatching 忽略 | 文件已被移走 |
