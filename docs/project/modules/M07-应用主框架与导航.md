# M07 应用主框架与导航

## 1. 职责与边界

### 模块职责
- 承载 Compose 应用外壳：MainActivity + Application + SmartStorageTheme。
- 主框架导航：三个主 Tab（首页/添加/设置）HorizontalPager 左右滑动 + 自定义底部栏双向同步。
- 子页面（编辑/详情/回收站/关于/捐赠）以全屏覆盖层叠加在 Pager 之上（不参与滑动）。
- 未保存修改保护、全局 Star 提醒弹窗、首次启动引导页路由。

### 不负责什么
- 不含各页面业务细节（M08~M12）；不含持久化/网络。

### 上下游关系
| 方向 | 模块 | 交换内容 | 约定 |
| --- | --- | --- | --- |
| 输入 | M06 ThemeRepository/OnboardingRepository/AppLanguage | 主题模式/引导/语言 | 订阅 Flow/SharedPreferences |
| 输出 | M08/M09/M11 页面 | 路由/页面切换 | Screen.route |
| 依赖 | M09 AddItemViewModel（Star 提醒）、M12 EmojiEffect | 全局弹窗/彩蛋 | - |

## 2. 功能清单
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| M07-01 | Pager 三 Tab 滑动 | pageCount=3；currentRoute 与 Pager 页同步 |

| M07-07 | 首帧主题 | MainActivity 冷启动按缓存主题设窗口背景，避免深色白闪 |

## 3. 核心流程
1. MainActivity.onCreate：runBlocking 读 themeMode → 设 window 背景 → setContent SmartStorageTheme(themeMode)。
2. MainScreen：rememberPagerState(3) + rememberSaveable currentRoute；底部栏点击 → navigateToTab（未保存先弹确认）。
3. 子页面通过覆盖层状态（editingItem/viewingItem/设置页内 currentRoute）切换；BackHandler 返回。
4. Star 弹窗状态提升到 MainScreen：添加成功触发，onStarGoToGithub 打开仓库并 markReminded。

## 4. 数据与接口
- 路由：`Screen`（sealed）：Home/Add/Edit/Detail/Settings/Trash/About/Donate（route 字符串）。
- 页面容器：`presentation/MainScreen.kt`；主题：`presentation/theme/SmartStorageTheme(themeMode)`。
