## 一句话说明

面向家庭的 Android 本地收纳管理工具：用户用语音/文字记录“物品放在哪”，App 通过 AI 或本地规则把口语解析为「名称 / 地点 / 备注」，支持多图附件、关键词与语义搜索、回收站、备份恢复与多语言/深色外观。
