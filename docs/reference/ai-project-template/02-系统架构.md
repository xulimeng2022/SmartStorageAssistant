## 变更规则

- 新功能先回到 [[01-需求与范围确认]]，确认是否在范围内。
- 涉及模块边界、数据流或技术选型时，先更新本文档，再创建实现任务。
- 某个模块内部的具体行为放入对应模块笔记；一次性测试输出放在任务卡，不写入本文档。
