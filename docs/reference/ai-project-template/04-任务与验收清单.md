## 任务关闭检查

任务勾选完成前，逐项确认：

- [ ] 需求和模块边界没有被扩大；如有变更，已记录在 [[07-变更与交付确认]]。
- [ ] 已先有失败测试，或已说明该项只能手工验收的原因。
- [ ] 已实现最小满足验收的行为。
- [ ] 受影响测试已通过，且结果已记录在任务卡。
- [ ] 稳定的接口、状态或决策已回写到对应模块笔记。
- [ ] 临时日志、真实数据、凭据和截图没有写入长期知识库或提交到仓库。
